# 🏠 House Price Prediction — EDA, Feature Engineering & Modeling

A complete end-to-end mini data science project: exploratory data analysis, feature
engineering, and price prediction on a residential housing dataset, plus an
interactive Streamlit demo app.

## Problem Statement

Predict a house's price (`price_lakh`) from four raw attributes:
`area_sqft`, `bedrooms`, `age_years`, `distance_city_km`.

## Workflow Covered

1. **Data loading & structure check** — shape, dtypes, summary stats
2. **Missing value analysis** — quantified and visualized with a heatmap
3. **Data quality check** — detected physically invalid values (negative area/price)
4. **Univariate & bivariate EDA** — histograms, boxplots, scatterplots, correlation heatmap
5. **Data cleaning** — invalid values → NaN → median imputation
6. **Feature engineering** — `area_per_bedroom`, `age_category`, `distance_bucket`,
   `is_far_from_city`, `bedrooms_area_interaction`
7. **Feature scaling** — `StandardScaler`, fit on train only (no leakage)
8. **Modeling** — Linear Regression, Random Forest (baseline + tuned via
   `GridSearchCV`), XGBoost
9. **Model comparison & feature importance**
10. **Model explainability (SHAP)** — global feature impact + a per-instance
    waterfall plot explaining one specific prediction
11. **Export** — best model, scaler, SHAP background sample, and price
    distribution saved to `models/` for the demo app

## What Makes This Different

Beyond the standard EDA → cleaning → FE → modeling flow, this adds two things
most quick submissions skip:

- **Live prediction explainability (SHAP):** the app doesn't just output a
  number — it shows a bar chart of which features pushed the predicted price
  up or down for that specific house.
- **Market-position gauge:** shows what percentile the predicted price falls
  into relative to the full dataset, so the number has context.

## Setup & Usage

### 1. Clone and install dependencies
```bash
git clone <your-repo-url>
cd house-price-prediction
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run the notebook (EDA + FE + training)
```bash
jupyter notebook notebooks/house_price_eda_fe.ipynb
```
Run all cells top to bottom. This regenerates `models/best_model.pkl` and the
other artifacts used by the app.

### 3. Run the demo app
```bash
streamlit run app/streamlit_app.py
```
Enter house details in the form and get an instant predicted price.
